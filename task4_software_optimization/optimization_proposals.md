# ⚡ Оптимизация системы напоминаний

## task: 1. Описать изменения, которые на Ваш взгляд, требуется произвести в ПО.
Предложить альтернативные варианты (не за счет текущего ПО) автоматизации потребностей компании «Авалор».

## Предлагаемые изменения

1. Реализовать уведомления не только посредством отправки e-mail сообщения, но и push-уведомления, так же можно использовать чат-боты для отправки уведомлений в мессенджеры. 
2. Необходимо реализовать: маску в поле "Дата события", а также использовать тип поля date для возможности выбора даты из календаря, так же для удобства пользователя можно автоматически заполнять дату следующего рабочего дня (в зависимости от рабочего календаря).
3. В поле e-mail для информирования необходимо установить маску для ввода. Так как сотрудник создает напоминания для себя или сотрудников своего отдела можно рассмотреть возможность выпадающего списка со сквозным поиском, чтобы при ручном вводе e-mail ошибок не возникало.
4. Добавить возможность устанавливать повтор события для напоминаний с выбором интервала и возможностью выбора времени (ручной ввод пользователя).
5. Добавить индикатор или статус события, а также возможность фильтрации задач по статусу.
6. Реализовать возможность типа "наблюдатель" или "участник события", которая позволит добавлять в задачи наблюдателей, которые смогут отслеживать статусы задач, а также видеть в своем списке/календаре общие задачи как еще один исполнитель.
7. Реализовать возможность фильтрации событий по количеству дней (1 день, 3 дня, 7 дней)
8. Реализовать переключатель интерфейса со списка в календарь, с возможностью отображения дня, недели, двух недель, месяца.
9. Добавить возможность синхронизации задач, например, для отдела, или группы пользователей. От данной доработки зависит п.6, так как синхронизации между ПК нет, то и при добавлении наблюдателя/исполнителя другой пользователь не узнает о задаче.
10. Реализовать фильтрацию для отображения списка просроченных задач из общего списка.

2. Предложить альтернативные варианты (не за счет текущего ПО) автоматизации потребностей компании «Авалор».

Альтернативные варианты:
1. Таблицы:
•	Примеры: Excel, Google Sheets
•	Описание: Использование электронных таблиц для ведения списка задач
2. Системы управления проектами:
•	Примеры: Trello, Asana, Jira, Microsoft Project, Monday.com
•	Описание: Специализированные инструменты для управления проектами и задачами
3. Программное обеспечение для управления задачами:
•	Примеры: Todoist, Wunderlist, Microsoft To Do
•	Описание: Простые приложения для ведения списка задач
6. Программное обеспечение для совместной работы:
•	Примеры: Slack, Microsoft Teams
•	Описание: Инструменты для командной работы, включающие функции управления задачами
