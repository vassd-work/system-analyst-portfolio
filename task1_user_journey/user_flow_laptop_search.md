# 🛒 User Flow: Поиск ноутбука в интернет-магазине

## task: Написать логическую цепочку последовательности действий пользователя "Интернет-магазина". 
Выбрать один из приведенных примеров: 
b. Пользователь ищет ноутбук с определенными характеристиками в определенной ценовой категории.


### Этапы

1. Поиск: 
•	Пользователь переходит на сайт интернет-магазина.
•	Пользователь вводит в строку поиска "ноутбук" или использует фильтры для поиска товаров в категории "Ноутбуки".
•	Пользователь устанавливает фильтры по характеристикам, как пример:
•	Размер экрана (например, 15 дюймов)
•	Тип процессора (например, Intel Core i5)
•	Объем оперативной памяти (например, 8 ГБ)
•	Объем жесткого диска (например, 512 ГБ SSD)
•	Ценовая категория (например, от 40 000 до 60 000 рублей)

2. Просмотр товаров:
•	Пользователь просматривает результаты поиска.
•	Пользователь изучает найденные варианты ноутбуков, сравнивает характеристики и цены.
•	Пользователь читает отзывы других покупателей.
•	Пользователь выбирает подходящий вариант ноутбука.

3. Выбор товара:
•	Пользователь переходит на страницу выбранного ноутбука.
•	Пользователь добавляет ноутбук в корзину.

4. Оформление заказа:
•	Пользователь переходит в корзину.
•	Пользователь проверяет выбранные товары и стоимость.
•	Пользователь выбирает способ доставки и оплаты.
•	Пользователь вводит контактные данные (имя, адрес, телефон).
•	Пользователь подтверждает заказ.

5. Оплата и доставка: 
•	Пользователь оплачивает заказ выбранным способом (онлайн-платежом, наличными при получении, банковским переводом).
•	Интернет-магазин обрабатывает заказ и отправляет его на доставку.
•	Пользователь получает уведомление о статусе заказа.
•	Пользователь получает заказ. 

Дополнительные действия:
•	Пользователь может добавить товар в избранное для последующего рассмотрения.
•	Пользователь может подписаться на рассылку интернет-магазина для получения информации о скидках и акциях.
•	Пользователь может оставить отзыв о купленном товаре.
